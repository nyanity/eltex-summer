## Структура репозитория

* `prepare_env.sh` — общий скрипт автоматической подготовки окружения для сборки (подходит для стандартных Linux-систем и WSL2).
* `lab1/` — Задание 1: Модуль Hello World с кастомными метаданными и лицензией.
* `lab2/` — Задание 2: Обмен данными через виртуальную файловую систему `/proc`.
* `lab3/` — Задание 3: Управление миганием клавиатурных светодиодов через `sysfs` и `ioctl`.
* `lab4/` — Задание 4: Обмен данными через драйвер символьного устройства (`chardev`).
* `lab5/` — Задание 5: Двунаправленный обмен данными по сетевым сокетам `Netlink`.
* `lab6/` — Задание 6 (Дополнительное): Фильтрация исходящих IP-пакетов через `Netfilter`.

## 1. Предварительная подготовка окружения (Environment Setup)

Для успешной сборки внешних модулей ядра (out-of-tree modules) требуются заголовочные файлы текущей запущенной системы. В WSL2 стандартный механизм установки заголовков не работает, поэтому в корне репозитория подготовлен автоматический скрипт.

### Инструкция по запуску:
1. Сделайте скрипт исполняемым:
   ```bash
   chmod +x prepare_env.sh
   ```

2.  Запустите его от имени обычного пользователя:
    ```bash
    ./prepare_env.sh
    ```

3. Сборка и очистка модулей

  - Для сборки модуля перейдите в его каталог и выполните:
    ```bash
    make
    ```
  - Для полной очистки каталога от временных файлов и скомпилированного модуля
    выполните:
    ```bash
    make clean
    ```
