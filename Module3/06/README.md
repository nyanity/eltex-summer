# Задание 6: Групповой UDP-чат (Широковещательная рассылка)

Равноправный децентрализованный групповой чат, работающий по сетевому протоколу UDP на базе широковещательных пакетов (Broadcast).

## Функционал

* При запуске клиент рассылает пакет JOIN:\<pid>:\<nickname>, уведомляя участников о своем появлении. При выходе или нажатии Ctrl+C рассылает пакет LEAVE:\<pid>:\<nickname>.
* Передача сообщений осуществляется в формате MSG:\<pid>:\<nickname>:\<payload>.
* Собственный loopback-трафик фильтруется и отбрасывается по полю PID. Прием сообщений ведется в параллельном потоке pthread, не блокируя ввод текста.

## Сборка
```shell
make
```
## Использование
```shell
./build/udp_chat [nickname] [port]
```
## Тестирование
```shell
make test  # Юнит-тесты
make run   # Интеграционный тест test.sh
```
