# Задание 4: Модель Производитель-Потребители (System V SHM + Semaphores)

Программа реализует модель параллельной обработки данных «Производитель-Потребители» с имитацией односвязного списка в разделяемой памяти System V.

## Архитектура

* В качестве адресов переходов (указателей) используются относительные байтовые смещения (offsets) от начала разделяемой памяти для обеспечения переносимости между адресными пространствами процессов.
* Производитель (-p): Периодически блокирует память семафором, упаковывает случайное количество элементов с выравниванием границ памяти по 8 байт и добавляет новый блок в хвост списка. Если память исчерпана, выставляет флаг finished_producer и засыпает. Перед завершением работы ждет обработки всех блоков потребителями, очищает семафоры и сегмент памяти.
* Потребитель (-c): Обходит список, находит первый необработанный блок (count > 0), ищет в нем минимальное и максимальное значение, выводит результат и помечает блок обработанным (count = 0). Может быть запущено несколько независимых процессов потребителей.

## Сборка
```shell
make
```
## Использование
```shell
# Запуск Производителя
./build/shm_prod_cons -p

# Запуск Потребителя (в отдельном терминале)
./build/shm_prod_cons -c
```
## Тестирование
```shell
make test  # Юнит-тесты
make run   # Интеграционный тест test.sh
```
