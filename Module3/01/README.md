# Задание 1: Копирование файлов (fork + pipe + FIFO)

Программа создаёт копии указанных в списке аргументов файлов, организуя строгое двухстороннее взаимодействие между родительским и дочерним процессами.

## Механика работы

1. Родительский процесс выполняет fork().
2. Перед началом передачи каждого файла дочерний процесс отправляет родителю 1 байт готовности.
3. Получив заголовок, родитель открывает исходный файл. Если файл отсутствует, родитель выводит диагностическую ошибку в stderr и отправляет дочернему процессу заголовок с типом сообщения MSG_TYPE_SKIP.
4. Если файл доступен, родитель отправляет заголовок MSG_TYPE_HEADER с метаданными (имя файла и размер).
5. Передача данных осуществляется блоками по 4096 байт. Дочерний процесс записывает полученные байты в файл с суффиксом .copy.
6. После обработки всех файлов родитель отправляет заголовок MSG_TYPE_DONE, дочерний процесс завершается, а родитель вызывает waitpid().
7. При использовании флага -p создаются два именованных канала (FIFO) с именами <name>_p2c (родитель-ребёнок) и <name>_c2p (ребёнок-родитель) для бесконфликтной передачи данных. При отсутствии флага используются неименованные каналы pipe().

## Сборка
```shell
make
```

## Использование
```shell
./build/file_copy [-p имя_канала] <файл1> [файл2 ...]
```

## Тестирование
```shell
make test  # Модульные тесты (GTest)
make run   # Интеграционный сценарий test.sh
```
