# Задание 8: Анализатор пакетов RAW-сокетов (UDP & DNS)

Программа низкоуровневого анализа сетевого трафика, получающая копии UDP-сегментов и выполняющая разбор заголовков канального, сетевого и транспортного уровней.

## Возможности анализатора

* Захват сырых Ethernet II кадров с использованием сокетов пакетов Linux (AF_PACKET, SOCK_RAW).
* Построчный разбор полей:
  * Временное смещение с точностью до микросекунд с момента начала сессии захвата.
  * MAC-адреса отправителя и получателя (из заголовка ethhdr).
  * IP-адреса отправителя и получателя (из заголовка iphdr).
  * Порты UDP отправителя и получателя (из заголовка udphdr).
  * Полезная нагрузка (Payload) с выводом печатных символов ASCII и HEX-экранированием управляющих байтов.
* Динамическая фильтрация трафика по любому порту для сообщений UDP-чата (Задание 6) и DNS-запросов.

## Сборка
```shell
make
```
## Использование

Для запуска RAW-сокетов требуются привилегии суперпользователя (root / sudo).

Перехват и разбор сообщений UDP-чата на порту 8889
```shell
sudo ./build/raw_capture -c 8889 10
```
## Перехват DNS-запросов на порту 53
```shell
sudo ./build/raw_capture -d 53 5
```
## Тестирование
Для автоматической сборки чата из Задания 6, генерации пакетов и проверки перехвата запустите:
