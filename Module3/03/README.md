# Задание 3: Одноранговый асинхронный чат (POSIX Message Queues)

Программа реализует P2P-чат между двумя равноправными терминалами с использованием двух очередей сообщений POSIX и многопоточности pthread.

## Особенности реализации

* Базовое имя очереди передается аргументом (например, /mychat). Программа преобразует его в две очереди: /mychat_1` и /mychat_2.
* Процесс, запустившийся первым, создаёт очереди с флагом O_EXCL, принимает сообщения через первую очередь и отправляет через вторую.
* Второй запустившийся процесс подключается к существующим очередям, отправляет сообщения в первую очередь и принимает из второй.
* Для бесконфликтного приема сообщений параллельно с вводом текста клавиатуры запускается фоновый поток mq_timedreceive.
* При отправке команды /quit или получении сигнала SIGINT отправляется служебный пакет с приоритетом PRIO_EXIT = 10. Процесс-создатель автоматически очищает очереди вызовом mq_unlink.

```

```
