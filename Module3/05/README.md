# Задание 5: Модель Производитель-Потребители (POSIX SHM + Semaphores)

Перенос многопроцессной архитектуры обмена данными из Задания 4 на системные вызовы стандартов POSIX с использованием именованных семафоров и разделяемой памяти.

## Реализация

* Для разделяемой памяти используются вызовы shm_open(), ftruncate(), mmap(), munmap(), shm_unlink(). Имя сегмента памяти: /posix_shm_pcons.
* Синхронизация доступа к односвязному списку осуществляется через именованные семафоры POSIX: sem_open(), sem_wait(), sem_post(), sem_close(), sem_unlink(). Имя семафора: /posix_sem_pcons.

## Сборка
```shell
make
```
## Использование
```shell
# Запуск Производителя
./build/posix_shm_prod_cons -p

# Запуск Потребителя (в отдельном терминале)
./build/posix_shm_prod_cons -c
```
## Тестирование
```shell
make test  # Юнит-тесты
make run   # Интеграционный тест test.sh
```
