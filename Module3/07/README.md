# Задание 7: Многопользовательский TCP-чат с передачей файлов

Клиент-серверное приложение чата, обеспечивающее надежный обмен сообщениями и файлами между подключенными клиентами по протоколу TCP.

## Архитектура мультиплексирования

* Сервер (chat_server): Использует механизм poll для одновременной обработки событий ввода-вывода (входящие соединения, получение данных, отключения) на множестве сокетов в рамках одного системного потока.
* Клиент (chat_client): Использует механизм select для одновременного контроля дескрипторов стандартного ввода (клавиатура) и сетевого сокета. При запуске клиентов в фоновом режиме (когда stdin перенаправлен на /dev/null) клиент динамически отключает опрос дескриптора 0 для предотвращения бесконечного холостого цикла.

## Передача файлов

* При вводе команды /file <путь_к_файлу> клиент считывает файл (размером до 32 КБ), упаковывает его в структуру file_payload_t и отправляет на сервер.
* Сервер транслирует файл всем участникам чата, которые сохраняют его на диск под именем <filename>.received.

## Сборка
```shell
make
```
## Использование
```shell
# Запуск сервера на порту 9999
./build/chat_server 9999

# Запуск клиента в соседнем терминале
./build/chat_client Alice 127.0.0.1 9999
```
## Тестирование
```shell
make test  # Юнит-тесты
make run   # Интеграционный сценарий test.sh с проверкой доставки файлов
```
