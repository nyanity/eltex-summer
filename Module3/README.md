#  Модуль 3

Лабораторные работы по изучению механизмов межпроцессного взаимодействия (IPC), сетевого программирования на сокетах и низкоуровневого анализа сетевых пакетов в операционных системах Linux/POSIX.

## Структура репозитория

* **01/** — Двухстороннее копирование файлов (fork + pipe + FIFO).
* **02/** — Издатель-Брокер-Подписчик (Очереди сообщений System V).
* **03/** — Одноранговый (P2P) асинхронный чат (Очереди сообщений POSIX + потоки).
* **04/** — Имитация односвязного списка в общей памяти (Разделяемая память + семафоры System V).
* **05/** — Имитация односвязного списка в общей памяти (Разделяемая память + семафоры POSIX).
* **06/** — Децентрализованный групповой UDP-чат (Широковещательная рассылка).
* **07/** — Многопользовательский TCP-чат с сервером и возможностью передачи файлов (poll / select).
* **08/** — Низкоуровневый анализатор сетевых UDP/DNS сегментов (RAW-сокеты).

## Сборка и тестирование
```shell
Сборка проектов координируется корневым Makefile динамически без жёсткого кодирования путей.
```
### Сборка всех лабораторных работ:
```shell
make
```
### Запуск модульных тестов (Google Test) для всех работ:
```shell
make test
```

### Сборка конкретной лабораторной работы (например, 01):
```shell
make 01
```

### Запуск юнит-тестов конкретной работы:
```shell
make test-01
```

### Запуск конкретной работы (тестовые сценарии shell):
```shell
make run-01
```

### Полная очистка:
```shell
make clean
```
