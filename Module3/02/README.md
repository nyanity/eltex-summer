# Задание 2: Модель Издатель-Брокер-Подписчик (System V Message Queues)

Асинхронная система обмена сообщениями, реализующая паттерн Publisher-Subscriber на очередях сообщений System V с обработкой системных сигналов.

## Компоненты системы

* Брокер (-b): Создает очередь сообщений с флагом уникальности IPC_EXCL. Слушает входящие сообщения с типом mtype = 1. Динамически хранит списки зарегистрированных подписчиков и издателей. Перенаправляет сообщения подписчикам, устанавливая mtype = subscriber_pid. При получении SIGINT рассылает сигнал завершения процессам клиентов и удаляет очередь.
* Издатель (-p \<topic>): Отправляет в очередь сообщения с темой и содержимым, устанавливая mtype = 1. Формат отправки: send,\<pid>,\<topic>,\<payload>.
* Подписчик (-s \<topic1> ...): Отправляет сообщение subscribe,\<pid>,\<topic> с типом 1 для регистрации подписки. Читает сообщения из очереди только своего типа mtype = getpid(). При выходе отправляет сообщение unsubscribe.

## Сборка
```shell
make
```
## Использование
```shell
# Запуск Брокера
./build/pubsub -b

# Запуск Подписчика на тему "news" и "sports"
./build/pubsub -s news sports

# Запуск Издателя в тему "news"
./build/pubsub -p news
```
## Тестирование
```shell
make test  # Юнит-тесты
make run   # Интеграционный тест test.sh
```
